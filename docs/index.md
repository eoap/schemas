# EOAP CWL custom types

This project proposes custom CWL types for Earth Observation Application Package inputs and outputs: GeoJSON geometries and features, OGC bounding boxes, STAC metadata, and string formats.

## Find what you need

The documentation follows [Diátaxis](https://diataxis.fr/), with four sections for different needs.

| Your goal | Start here |
| --- | --- |
| Learn by running a complete example | [Tutorials](tutorials/index.md) |
| Import a schema or define a new type | [How-to guides](how-to/index.md) |
| Look up types and schema definitions | [Reference](reference/index.md) |
| Understand the design and its limits | [Explanation](explanation/custom-types.md) |
