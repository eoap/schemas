# How-to guides

Use these guides when you have a specific task and already know the basics of CWL tools and input documents.

- [Use an existing schema](use-schema.md): import a schema and select a named input type.
- [Define new types](../newtypes.md): create a schema, import it, and validate a tool that uses it.

For a guided introduction, start with the [first-input tutorial](../tutorials/first-input.md). For field definitions, consult the [reference](../reference/index.md).
