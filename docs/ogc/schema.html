Fields

required
type
description
bbox
required
array<double>

Four or six numbers, depending on whether the coordinate reference system includes a vertical axis (height or depth).

crs
required
CRS

If the bbox value consists of four numbers, the coordinate reference system is WGS 84 unless a different coordinate reference system is specified.

If the bbox value consists of six numbers, the coordinate reference system is WGS 84h longitude/latitude/ellipsoidal height unless a different coordinate reference system is specified.
