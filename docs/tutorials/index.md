# Tutorials

Learn to pass structured inputs to CWL tools through worked examples. Start with [your first custom-type input](first-input.md), which covers setup, execution, and inspecting the result.

## Explore other inputs

These notebooks show the CWL tool, its input document, and the execution output. To run their shell commands yourself, use the repository root and the environment prepared in the first tutorial.

- GeoJSON: [Point](../geojson/point.ipynb) and [Feature](../geojson/feature.ipynb).
- OGC: [Bounding box](../ogc/bbox.ipynb).
- STAC: [Catalog](../stac/catalog.ipynb), [Collection](../stac/collection.ipynb), and [Item](../stac/item.ipynb).
- String formats: [Date and time](../string-format/datetime.ipynb) and [URI](../string-format/uri.ipynb).

## Experimental examples

[Discovery inputs](../experimental/discovery.ipynb) and [process inputs](../experimental/process.ipynb) demonstrate experimental schemas. Treat them as exploratory examples whose interfaces may change.

For the design constraints behind the examples, see [custom types and their limits](../explanation/custom-types.md).
